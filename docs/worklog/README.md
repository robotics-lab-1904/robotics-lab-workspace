# Worklog

This directory stores chronological, evidence-backed reports of completed and ongoing work.

Create one report per coherent task using:

```text
YYYY-MM-DD-SHORT-TASK-NAME.md
```

Use `../templates/TASK_REPORT_TEMPLATE.md`. Reports are appendable historical records: do not erase failed experiments or rejected hypotheses. Mark corrections explicitly so future agents understand why the approach changed.

The root `AGENTS.md` should link to stable context, not every report. Add reports to this index when they are important entry points.
