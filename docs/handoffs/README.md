# Agent Handoffs

`CURRENT.md` is the concise continuation point for unfinished work. It should describe the present state, not repeat the entire worklog.

When a task is completed or superseded:

1. move its detailed evidence to `docs/worklog/`;
2. create an archived handoff only if the transition itself matters;
3. replace `CURRENT.md` with the next active state or the explicit statement that no task is active.

Use `../templates/HANDOFF_TEMPLATE.md` for archived handoffs.
